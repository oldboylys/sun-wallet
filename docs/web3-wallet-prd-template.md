## 3. 页面流程（含状态流转）

### 3.1 主流程（推荐用例）

1. 启动扩展 -> 登录页
2. 输入密码 -> 解锁成功 -> 首页
3. 首页点击“发送” -> 发送页填写地址/金额 -> 确认交易页 -> 提交
4. 首页点击“接收” -> 收款页展示地址 + 二维码
5. 登录页点击“忘记密码” -> 风险确认 -> 重置流程

### 3.2 页面清单

- P-01 登录页
- P-02 忘记密码页
- P-03 首页（资产概览）
- P-04 发送页
- P-05 收款页
- P-06 交易确认页（可占位）
- P-07 交易结果页（可占位）

### 3.3 页面状态

- 登录页：默认 / 输入中 / 可提交 / 提交中 / 失败提示
- 发送页：地址非法 / 金额非法 / 余额不足 / 网络异常
- 收款页：二维码生成中 / 生成成功 / 生成失败

## 4. 异常场景（必须评审）

| 场景编号 | 场景描述 | 触发条件 | 期望处理 | 用户提示文案 |
| --- | --- | --- | --- | --- |
| EX-01 | 密码错误 | 用户输入密码不匹配 | 阻止进入首页，保留输入框状态 | [密码错误，请重试] |
| EX-02 | 助记词格式错误 | 导入时词数或词序异常 | 阻止导入，标红输入项 | [助记词格式不正确] |
| EX-03 | 私钥格式错误 | 非 64 位十六进制 | 阻止导入，给出示例 | [私钥格式不正确] |
| EX-04 | RPC 不可用 | 请求节点超时/失败 | 展示降级状态，可重试 | [网络繁忙，请稍后重试] |
| EX-05 | 地址非法 | 发送页地址校验失败 | 禁用下一步按钮 | [请输入有效地址] |
| EX-06 | 余额不足 | 输入金额 > 可用余额 | 阻止提交 | [余额不足] |
| EX-07 | 用户拒签 | 签名弹窗拒绝 | 回退至发送页并保留表单 | [已取消交易] |
| EX-08 | 广播失败 | 链上广播报错 | 提供重试与查看详情 | [交易发送失败] |

## 5. 验收标准（Acceptance Criteria）

### 5.1 功能验收

- [ ] 登录页：空密码时“解锁”按钮禁用
- [ ] 登录页：有密码时“解锁”可点击并进入首页
- [ ] 忘记密码页：风险项未全选时“重置钱包”禁用
- [ ] 首页：可进入发送页/收款页
- [ ] 发送页：地址与金额都合法时“下一步”可点击
- [ ] 收款页：二维码可见，地址可复制（至少有成功反馈）

### 5.2 交互与视觉验收

- [ ] 遵循 `UI_STYLE_GUIDE.md`（组件、token、布局）
- [ ] 380x620 视窗无横向滚动
- [ ] 所有按钮具备 hover/disabled 状态
- [ ] Toast 提示统一样式与位置

### 5.3 技术验收

- [ ] 构建命令通过（`npm run build`）
- [ ] 无新增 linter 错误
- [ ] 关键异常可复现并有可理解提示
